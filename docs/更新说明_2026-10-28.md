# OpenVisionForge 更新说明

日期：2026-10-28

本次是源码与文档同步更新，没有发布新的安装包，也没有修改版本号。

## 主要更新

- 同步 Rust 核心、React/Tauri Studio、节点实现及工作流示例。
- 补充 ROI、比例尺、单位转换、相机标定和去畸变相关实现及示例。
- 完善节点执行条件、关键 NG 短路、标准检测结果和记录输出。
- 补充 YOLO 分类、实例分割、Pose、OBB 解码，以及模型目录校验、ONNX Runtime Session 复用相关实现。
- 增加模型 registry、COCO/DOTA 类别配置；模型权重仍需单独准备。
- 增加帧上下文、文件夹连续读图、流式统计和视频读帧节点基础。
- 更新中英文 README、项目进度、发布检查和合成标定样本。

以上内容由主开发目录同步至 GitHub 发布目录，不代表这些功能全部在本次新开发。

## 使用注意

- 当前 OpenCV bridge 构建依赖 Windows、MSVC 和 OpenCV 5；跨平台构建尚未完成。
- ONNX CPU 推理需准备匹配的模型权重和 ONNX Runtime 1.22.0，并配置 `ORT_DYLIB_PATH`。
- SDK、权重、本机测试图片、编译产物及运行记录不随本次源码上传。
- 部分数据库、消息队列和存储节点目前生成请求或 outbox 文件，真实 SDK 接入仍需完善。
- 阶段 8 仍在进行：并发流式执行、真实背压、视频流整合、检测触发抓拍和硬件适配尚未完成。
